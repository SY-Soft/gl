# GL.UA test task

Проект создан как тестовое задание для GL.UA.

Drupal 11 поднимал на своем Docker/LAMP окружении, которое недавно собрал для себя в рамках изучения Docker и современных подходов к локальной разработке:

https://github.com/SY-Soft/practice_docker

В окружении используется мультипроектная структура и wildcard-домены вида:

```text
project.localhost
```

Для демонстрации проект также развернул на своем хостинге:

https://gl.sy-soft.net

## Доступ

```text
Логин: admin
Пароль: adminadmin
```

## Что реализовано

* страница `/my-first-page`
* вывод текущей даты/времени
* отключение кеширования страницы
* AJAX-форма
* блок с выводом текущего route name
* сервис с использованием `entity_type.manager`

## Что было сложным

Основная сложность возникла при настройке Docker/nginx под Drupal 11.

До этого wildcard-домены у меня смотрели в `/public`, а в Drupal 8+ document root должен указывать в `/web`.

Также немного замешкался при деплое проекта на хостинг.

В целом на выполнение ушло около 5 часов.
